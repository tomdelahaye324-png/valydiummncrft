# VALYDIUM : projet à compiler sur Windows
1. Installer le SDK .NET 8 et Inno Setup 6.
2. Double-cliquer sur build.bat -> dist\VALYDIUM_Installer.exe
Rien de ceci n'a été compilé ni testé (aucun environnement Windows disponible).

## Sans rien installer : GitHub
Crée un dépôt GitHub gratuit, envoie-y tout le contenu de ce dossier (y compris .github),
onglet Actions -> "Build VALYDIUM Installer" -> Run workflow. A la fin, télécharge
l'artefact "VALYDIUM_Installer" : il contient VALYDIUM_Installer.exe.
